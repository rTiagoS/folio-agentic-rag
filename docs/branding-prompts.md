# Branding assets

Generated with the built-in image generation tool, with transparent backgrounds.
The text-free mark is reused under the current project name; its design brief below
uses that name. The PNG assets are saved as `folio-icon.png` and `user-icon.png`.

## Folio mark

Use case: logo-brand. Create one final standalone PNG brand icon for Folio, a clean executive document-chat application with a white and pale-slate interface and blue accents. Subject: a distinctive, beautifully balanced geometric mark combining a folded document page and a conversational speech bubble through negative space. Modern, understated, professional, flat vector-like graphic, precise edges, bold simple silhouette readable at 32px. Palette matching the application: deep navy and clear royal blue, with at most a restrained azure accent. Square canvas, single centered icon occupying about 80% of the frame with even transparent padding. Actual transparent alpha background. No text, letters, wordmark, gradients, shadows, glow, surrounding badge, mockup, watermark, or decorative objects. Deliver only the icon.

## User avatar

Use case: logo-brand. Create one final standalone PNG user-avatar icon for a modern executive document-chat interface. A neutral anonymous human head and shoulders, clean restrained outline design, centered inside a thin open-air circular outline, similar to a standard account/profile icon. Deep slate-navy stroke, balanced consistent medium stroke, simple and highly legible at 32px. Flat vector-like graphic, square canvas, centered subject occupying about 80% with even padding. Actual transparent alpha background including inside the circle, no white fill or rectangular background. No letters, text, realism, facial details, shadows, gradients, glow, mockup or watermark. Deliver only the icon.
